// CAPABILITIES

桌面级 IDE，移动端形态

把 Linux 运行时、X 服务和渲染通道全部塞进一个 APK，安装后按需下载镜像与 IDE。

01

官方 PyCharm

直接运行 JetBrains 官方 Linux arm64 构建，社区版 2022.3–2025.3、专业版 2022.3–2026.3 可选。

02

免 root 容器

Termux 版 proot + 自编译 loader，绑定 /dev、/proc、/sys，Android 8.0 以上即可运行。

03

原生 RFB

不走 noVNC / WebView。Raw + CopyRect 编码直接写 Bitmap，省掉 JS 解码与两次内存拷贝。

04

触控与键盘

单指移动/轻点/长按拖拽、双指缩放平移、双指右键，自绘六行软键盘直接注入 keysym。

// ARCHITECTURE

一条链路，五层运行时

x11vnc 只发 Raw 像素，客户端直接绘帧；端口固定 5901，启动脚本每次从 APK 刷新。

APK→ proot · Ubuntu 24.04 arm64→ Xvfb :1→ x11vnc :5901→ Native RFB→ Canvas · Bitmap

三步跑起来

首次安装需要下载约 30 MB 系统镜像与 750 MB–1.3 GB IDE，建议 Wi-Fi + 至少 8 GB 空闲存储。

1

安装 APK

下载最新版 arm64 APK，允许「安装未知应用」。覆盖安装即可升级，容器与项目文件保留。

2

开始安装

打开应用点「开始安装」。自动校验 SHA-256、解包 Ubuntu base、apt 安装 X11/VNC、下载并解包 PyCharm。

3

启动 PyCharm

点「启动 PyCharm」进入桌面。首次 JVM 冷启动 1–3 分钟，之后固定连接 127.0.0.1:5901。

// FAQ

常见问题

关于性能、账号与兼容性的高频问题。

需要 root 吗？

不需要。使用 proot 用户态模拟，未解锁 Bootloader 的零售机也能安装。代价是 ptrace 带来的系统调用开销，启动阶段最明显。

堆内存怎么调？

主界面点「堆内存」，可选 512 / 768 / 1024 / 1536 / 2048 / 3072 MB。已安装时直接改写容器内 pycharm64.vmoptions，重启 PyCharm 生效；安装过程中则自动写入所选档位，重复调整不会叠加多个 -Xmx。

为什么强制横屏？

PyCharm 桌面 UI 按 16:10 设计，竖屏下编辑器与工具窗口会被压得很窄。v1.9.9 起主界面和显示页都锁定 sensorLandscape，可左右翻转，但不会回到竖屏。

为什么首次启动很慢？

要等 Xvfb 就绪、JBR 冷启动、PyCharm 索引初始化。7 GB 内存设备建议只开一个项目，社区版比专业版轻。

专业版需要账号吗？

需要。专业版首次启动会要求登录 JetBrains 账号激活，含 30 天试用；社区版免费，无需账号。

支持哪些设备？

arm64 设备、Android 8.0+、至少 7 GB 内存；安装 IDE 需要 8 GB 以上空闲存储。x86 设备不适用。

解包或卸载时会卡住吗？

v1.11.0 起解包会显示压缩包字节、总量、百分比和当前文件；卸载先统计文件数/体积，再按删除字节推进。大目录首次扫描需要几秒，属于正常现象，系统会持续更新进度。

日志面板无法滚动/为什么有个大鼠标？

v1.14.1 起日志区禁用文本选择并支持上滑后停止自动跟随；VNC 通过 RichCursor 使用 x11vnc 的真实 X11 指针，空光标隐藏，异常大光标限制 24dp。

为什么修改堆内存后没生效？

v1.14.0 起堆参数写入 /opt/host/vmoptions.txt，启动脚本用 PYCHARM_VM_OPTIONS 覆盖安装目录和用户配置；修改后必须停止并重新启动 PyCharm，JVM 才读取新 -Xmx。旧版只改安装目录默认文件，遇到用户配置副本会被覆盖。

v1.13.0 性能优化做了什么？

RFB 输入/输出加缓冲，协议小字段不再逐字节走 socket；Raw 像素用 little-endian IntBuffer 批量读入；ide.log 的读取与拼接移到后台单线程；TarGz 普通路径不再逐条 canonical，目录创建结果缓存，无执行位文件跳过冗余 chmod；rootfs 已可执行时不再重复 chmod。

v1.12.0 性能优化做了什么？

rootfs 校验结果缓存，避免每次启动遍历 usr/bin；解包复用 64 KB I/O 缓冲；主界面空闲轮询降到 2 s；显示页日志面板隐藏后停止日志读取；VNC 更新按帧合并，CopyRect 原地拷贝。

为什么端口固定 5901？

display :1 的传统 VNC 端口。服务端和客户端都写死 5901，避免端口扫描带来的连接抖动。
